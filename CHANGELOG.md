# Changelog

## 0.2.0-alpha.1 — Themes

- Ten original palettes with a searchable gallery, favorites, live preview, save/cancel and up to twelve personal presets.
- Shared colors for native navigation, category chips, forms, offer rows and chats; readable accent button labels and link colors.
- Optional clean layout hides FunPay's large decorative banner. Local CSS backgrounds, custom image shading, radius, typography and density controls.
- Themes load at document start; the workspace follows the selected palette, including light mode. Smaller launcher, responsive navigation and reduced-motion support.
- Independent sound settings, import/export preview and one-step native appearance reset.
- Contrast and preview regression tests; Firefox runtime check covers all ten themes, native table geometry and reset on a disposable local fixture. Live authenticated website operations remain unverified.

## 0.1.0 — 2026-10-22 · alpha

Original Firefox implementation and visual identity. Eight-section workspace, native page helpers, local history, listing/chat tools, guarded automation, opt-in external integrations, test suite, offline preview and GitHub CI. This is a development release; see `docs/STATUS.md` for unverified website operations and features not yet implemented.

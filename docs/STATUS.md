# Состояние Oblivion 0.1.0

## Что проверено

- Чистые функции: настройки, фильтрация/нормализация импорта, цены, даты, подстановка переменных, статистика, экспорт CSV, очистка backup.
- Фоновая логика с имитацией API: старт без ретроактивных ответов, новый чат, повторное сообщение, чёрный список, новая стартовая точка при смене правил/склада, задержка поднятия, резервирование и неопределённая выдача.
- Восемь разделов интерфейса в DOM-тесте, сохранение заметок, безопасный вывод сообщений, валидация правил, закрытие и повторное открытие.
- Работа демо аналитики и чатов в браузере, визуальная проверка интерфейса. Скриншоты в README показывают вымышленные данные.
- Mozilla `web-ext lint` без ошибок и предупреждений; сборка ZIP.
- Отдельный runtime smoke test в настоящем Firefox настроен в CI. Результат проверяйте в Actions для текущего коммита. Локальный запуск Firefox 158 в изолированной среде не смог установить соединение с отладчиком; это не считается успешной проверкой.

## Что ещё требует ручной проверки

Нет подтверждения реальных операций в авторизованном FunPay: серверного принятия сообщений/изображений, клонирования и сохранения лотов, пагинации финансов/заказов, поднятия и планирования, живой автовыдачи. Также не проверены живые AI/Telegram/Discord-запросы с ключами владельца. Адаптер использует HTML и протокол публичного клиента сайта, а не гарантированно стабильный официальный API.

На первой версии используйте отдельный тестовый лот и тестовый чат. При ошибке обновите страницу/сессию и проверьте результат на самом сайте перед повторной ручной операцией.

## Отличия от полного набора функций Foxen

Полный паритет **не достигнут и не заявляется**. В частности, в этой версии отсутствуют:

- аккаунт Foxen, его облачный каталог, Supabase, RMT Hub и связанные социальные интеграции;
- перенос ключей аккаунтов Firefox Containers и переключение учётных записей по сохранённым сессионным ключам;
- автоматическая благодарность за отзыв, бонус за оценку и отдельные правила статусов заказа;
- клонирование чужих публичных лотов и создание новых лотов импортом; текущий импорт меняет только существующие собственные ID;
- массовое редактирование всех произвольных полей каждой категории, управление сложными вариантами товаров;
- полноценный визуальный Live Styler с выбором элементов страницы, генератор частиц и анимированных ников;
- редактирование публичного профиля/баннера, автообработка тикетов поддержки, Discord-команды и расширенный набор Telegram-команд;
- автоматические рыночные курсы валют, гарантированный полный экспорт истории и восстановление склада из обычного backup.

Профильные поля без работающего интерфейса не используются. Эти функции не заменены кнопками-заглушками. Следующий этап — подтвердить базовый адаптер на действующем FunPay и расширять поддержанные сценарии отдельными изменениями и проверками.

## Распространение

GitHub-релиз — предварительный, ZIP без подписи Mozilla. Для временной установки выбирайте `manifest.json` через `about:debugging`. Для постоянной установки сначала требуется подписание через Mozilla для самостоятельного распространения; публикация в AMO-каталоге не обязательна.

# Конфиденциальность

Oblivion не содержит телеметрии, рекламы и своего сервера. Настройки, заметки, шаблоны, склады, журнал и история хранятся в `storage.local` и IndexedDB Firefox.

## FunPay

Чтение и изменение лотов, история, сообщения и автоматизация обращаются к `https://funpay.com` с текущей браузерной сессией. Расширение не экспортирует cookies и не сохраняет пароль FunPay. Оно работает с уже авторизованной сессией и правами вашей учётной записи.

## Опциональные внешние функции

- OpenAI (`api.openai.com`), OpenRouter (`openrouter.ai`) или Google Gemini (`generativelanguage.googleapis.com`): введённый/выбранный вами текст, заданная модель и ваш API-ключ. Сообщения целиком не отправляются без соответствующего действия пользователя. Для картинок отправляется введённый промпт.
- Telegram (`api.telegram.org`): токен бота, ID чата, уведомления с именем пользователя и фрагментом нового сообщения или названием заказа. Команды принимаются только из указанного чата.
- Discord (`discord.com`): webhook, уведомления с аналогичными данными. Массовые упоминания в сообщениях отключены.

Доступ к доменам запрашивается по действию пользователя. Перед запросами дополнительно проверяются опциональные разрешения Firefox на передачу данных, а для AI — локальное согласие. Выключение функции, общая пауза и отзыв разрешений прекращают новые соответствующие операции. Уже переданные данные регулируются политиками выбранных сервисов.

## Локальные секреты и экспорт

API-ключи, токен Telegram и Discord webhook хранятся локально без отдельного шифрования. Обычный backup их не содержит. Склад автовыдачи и зарезервированные строки также исключены из обычного backup, чтобы случайно не раскрыть товары/коды. Импорт сохраняет текущий локальный склад и секреты, но выключает автоматизацию и внешние интеграции. API-согласие при импорте сбрасывается.

Экспорт заметок, шаблонов, лотов и CSV выполняется только по вашему действию. Он может содержать персональные данные покупателей и информацию о ваших товарах; сами файлы не загружаются на GitHub или какой-либо сервер расширением.

Удаление расширения/его браузерных данных удаляет локальное хранилище средствами Firefox. Репозиторий проекта не содержит пользовательских сессий, токенов, складов или истории заказов.
